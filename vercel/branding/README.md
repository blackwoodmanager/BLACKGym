# BlackGym icons

Put the app's own icons here, one square PNG each, 1024 × 1024, drawn to the edges (no rounded
frame: the phone rounds the corners itself):

| File | Icon |
|---|---|
| `kettlebell.png` | Kettlebell with the letter B (the default) |
| `back.png` | Athlete's back |
| `dumbbell.png` | Dumbbell in a red ring |
| `logo.png` | Letter B with the BLACKGYM wordmark |

They are not part of openGym and not covered by its licences: they belong to the owner of this
deployment.
